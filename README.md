# Tarkov Gear Store & Telegram Bot (Django + aiogram)

Навчальний вебмаркетплейс ігрового спорядження (боєприпаси та засоби захисту) зі спільною базою даних для сайту та Telegram-бота.

### 🛠 Стек технологій
- **Web Backend:** Python 3, Django (Function-Based Views, ORM, Sessions)
- **Telegram Bot:** aiogram 3, aiosqlite (асинхронна робота з БД)
- **База даних:** SQLite3 (єдиний файл бази для сайту та бота)
- **Інтерфейс:** HTML5, CSS3, Django Templates, Bootstrap

### ⚙️ Реалізований функціонал

#### Вебзастосунок (Django):
- **Каталог товарів із фільтрацією:**
  - Набої (`Product`): фільтрація за калібром та типом боєприпасу (`icontains`).
  - Бронежилети (`Vest`): класифікація за класом захисту, вагою та ціною.
- **Два механізми кошика:**
  - Базовий кошик для набоїв через реляційні моделі (`CartItem`).
  - Окрема сесійна корзина для бронежилетів (`request.session`).
- **Управління замовленнями:**
  - Формування замовлення (`Order` / `OrderItem`) із фіксацією ціни на момент покупки (`price_at_time`).
  - Історія замовлень користувача.
- **Рольовий доступ (RBAC):**
  - Кастомний декоратор `@admin_required` для операцій додавання/видалення позицій адміном.

#### Telegram-бот:
- Авторизація користувача з перевіркою за обліковим записом Django (`/login`).
- Перегляд актуального каталогу набоїв та бронежилетів із динамічною відправкою фотографій (`FSInputFile`).
- Синхронізація історії замовлень із сайту прямо в чат Telegram (вибірка через `LEFT JOIN`).
- Команда перегляду статистики бази даних магазину (`/stats`).
